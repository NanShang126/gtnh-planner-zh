GTNH Planner 中文汉化

给 gtnhplanner.com（GregTech: New Horizons 工厂规划器）加上简体中文界面与物品名词典。
原站功能、数据、存档完全不受影响 —— 本项目只是在浏览器里加了一层"中文翻译滤镜"。

1它做了什么

  • 界面汉化：顶部导航、搜索栏、建造/求解/汇总面板、资源统计、共享方案页等全部固定文案。
  • 物品 / 流体 / 机器名汉化：内置约 3.2 万条 官方简体中文译名（源自 GTNH 官方中文本地化数据，覆盖 GregTech、Thaumcraft、Botania、AE2 等主要模组）。
  • 智能拼接：词典没有的复合词（如「小撮××粉」「××单元」「熔融××」）会按 GT 命名规则自动拼出中文。
  • 实时翻译：搜索结果、卡片、悬浮提示出现的新文字会被即时翻译，无需刷新。
  • 一键开关：油猴菜单里点「汉化 开/关」即可切回英文原版。

4使用与开关

  • 开关汉化：点击浏览器右上角 Tampermonkey 图标 → 「GTNH Planner 中文汉化」 → 「汉化 开/关」。
  • 控制台方式：在站点按 F12 打开控制台，输入 __GTNH_ZH_TOGGLE__() 回车。
  • 你的方案存档保存在原站（本机/账号），与汉化脚本完全无关，随时可切回英文。

6更新与反馈

脚本内置词典为静态数据。原站更新后如果出现新的未翻译文案，属正常现象，不影响功能。想补充词条可编辑仓库里的 src/ui_dict.js，重新运行 node src/build.js 即可。
